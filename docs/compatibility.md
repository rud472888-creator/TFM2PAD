# 호환 범위와 업데이트

| --- | --- |
| 게임 | Steam App ID 3009300, macOS판 0.7.1, build 26425267 |

| 빌드 환경 | Apple Silicon Mac, macOS 27.0.1, Xcode 27.1, Python 3.11 이상. iPhoneOS SDK가 포함된 전체 Xcode 필요 |

실기 결과는 이 키트의 기반이 된 개인 빌드에서 측정했다. 새 Mac에서 컴파일과 서명에 성공하면 그 Mac에서 앱을 만들었다는 뜻이다. 해당 구매자의 Steam 로그인, 터치, 세이브는 iPad에 설치한 뒤 확인한다.

## 공개 소스 재현 검사

2026-11-07, 공개 파일만 있는 새 디렉터리에서 README의 `doctor → check → build` 경로를 실행했다. 고정된 GL4ES를 다시 내려받고 구매한 Mac 설치본으로 새 iPad 앱을 빌드했다. 별도 선택 모드 경로에서는 네 모드, 원본 일러스트 입력 및 연봉 패치까지 패키징하고 기존 Apple 개발 프로필로 앱을 서명했다. 서명 검사는 앱·내부 라이브러리의 코드 서명, 인증서, 팀과 키체인 그룹을 확인했다. 이번 공개 준비에서는 이 새 서명본을 iPad에 재설치하지 않았다.

Xcode 또는 SDK가 달라지면 컴파일된 Steam 오디오 호환 라이브러리의 해시가 달라져 빌드가 중단될 수 있다. 지원 여부를 확인할 때는 위에서 검증한 Xcode 27.1을 기준으로 삼는다. 검사를 통과시키기 위해 임의의 해시를 등록하지 않는다. 프로필 JSON에 들어 있는 기기 시험 메모는 패치를 작성하던 당시의 기록이며, 현재 확인한 기능은 위 표에 정리했다.

## 업데이트가 나오면

1. Mac의 Steam에서 공식 업데이트를 받은 후 다시 `python3 scripts/build.py check`를 실행한다.
2. 파일이 기존 프로필과 맞으면 새 출력 폴더에 빌드한다. 기존 캠페인을 이어갈 때에는 같은 Apple Team과 번들 ID로 서명한다. 게임을 닫고 설치 도구의 저장 백업을 완료한 뒤 덮어 설치한다.
3. 게임이나 Steam 클라이언트 해시가 바뀌면 그 버전은 지원 대기다. 파일 이름과 Steam build ID로 이슈를 작성할 수 있다. `work/` 파일과 전체 로그는 개인 정보를 담을 수 있으므로 업로드하지 않는다.

게임은 로컬 Steam 캐시에서 새 빌드 정보를 확인할 수 있다. 서버의 최신 버전 확인이나 iPad 단독 게임 업데이트는 별도 기능이다. 빌드 중 다른 사용자의 게임이나 Steam 바이너리를 내려받는 경로는 없다.

## 첫 실행 확인

앱 아이콘 → Steam Guard QR 승인 → 메인 메뉴 → 새 캠페인. 감독 이름을 입력하고 첫 저장을 만든 후, 앱을 다시 열어 자동 로그인과 이어하기가 되는지 확인한다. 검색칸은 한 번 탭해 입력하고 선수 목록은 한 손가락으로 위아래로 쓸어 넘긴다. 키보드를 수동으로 열 때는 두 손가락 탭이나 하드웨어 키보드의 ⌘K를 쓴다. 캠페인과 경기 중에는 자주 저장하는 편이 좋다.
