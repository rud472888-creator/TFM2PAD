# iPad host

The public build first compiles this UIKit host, then stages the purchaser’s game, Steam client and compatibility libraries. The finished app uses the online launch path. The standalone host before staging can only survey available APIs.

For a playable build, start at the [repository guide](../../README.md). The low-level standalone API diagnostic is useful when reviewing a new OS or game version. Its symbol lookup only establishes availability on that device. A fresh runtime survey alone cannot approve an updated game or Steam client.
